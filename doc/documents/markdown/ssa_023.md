# 补充安全收入（SSI）福利 | 社会保障署

补充安全收入（SSI）项目向有限收入和资源的残疾成人和儿童支付福利。

SSI福利也支付给没有残疾但符合财务限制的65岁及以上的人。

那些工作足够长的人也可能能够同时获得社会保障残疾或退休福利以及SSI。了解更多关于SSI的信息。

### 我如何申请SSI？

如果您想为以下情况申请SSI福利：

### 残疾成人

您现在可以在线申请补充安全收入（SSI），但前提是您符合某些要求。如果您符合以下条件，您可以在线申请SSI：

- 年龄在18至65岁之间；
- 从未结婚；
- 不是盲人；
- 是居住在美国五十个州、哥伦比亚特区或北马里亚纳群岛的美国公民；
- 从未申请或获得过SSI福利；和
- 同时申请社会保障残疾保险。了解您是否有资格获得社会保障残疾福利。

在线申请SSI和残疾福利

完成在线流程后，社会保障代表将联系您，以获取申请所需的所有其他信息。

您也可以预约前往当地的社会保障办公室提交申请。周一至周五上午7点至下午7点，拨打1-800-772-1213（聋哑人士或听力障碍者请拨打TTY 1-800-325-0778）或联系当地社会保障办公室。

在我们的残疾福利页面了解更多并开始残疾申请流程。

### 有残疾的儿童

社会保障目前还没有为儿童福利申请的在线申请。请访问申请残疾福利（未满18岁）以申请您的孩子。

如果您现在准备好申请，可以完成在线儿童残疾报告。

### 65岁及以上的人

- 拨打1-800-772-1213。如果您是聋哑人士或听力障碍者，可以拨打TTY 1-800-325-0778，或
- 访问您当地的社会保障办公室。（先打电话预约。）

### 我的SSI申请被拒绝了，我能提出上诉吗？

可以，如果我们最近拒绝了您的SSI申请，您可以在线提出SSI上诉。要了解更多信息，请阅读如何提出上诉。

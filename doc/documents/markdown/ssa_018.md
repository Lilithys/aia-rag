# 获取社会保障卡所需文件 | 社会保障管理局

### 外籍出生的美国公民成人的更正卡

如果因為結婚、離婚、法院命令或其他原因合法更改姓名，你需要告訴社會保障局，以便獲得更正的卡。如果你正在工作，也需要告訴你的雇主。如果你不告訴我們姓名更改的事宜，可能會：

- 可能会导致你的工资未被正确记录到社保记录中，从而降低你未来社保福利的金额。
- 可能会导致你在报税时出现延误。

重要

您必须出示原件或由颁发机构认证的复印件。我们不接受复印件或公证复印件。所有文件必须是当前有效的（未过期）。我们不接受显示您已申请该文件的收据。

我们可能会使用一份文件来证明两个目的。例如，我们可以使用您的美国护照来证明您的公民身份和身份。

### 我需要哪些原始文件？

公民身份

如果您尚未向我们确立美国公民身份，我们需要看到美国公民身份的证明。我们只能接受某些文件作为美国公民身份的证明。这些包括：

- 美国护照；
- 归化证书（N-550/N-570）；
- 公民证书（N-560/N-561）；
- 出生报告证书（DS-1350）；
- 外交护照出生报告（FS-240，CRBA）。

重要的是

我们只需在您尚未通过我们确立美国公民身份的情况下才需要此文件。

姓名变更

如果您需要更改社保卡上的姓名，必须向我们提供证明您合法更改姓名的文件。社保可能会接受以下文件来证明合法姓名变更：

- 婚姻文件；
- 离婚判决书；
- 归化证书显示新的姓名；或
- 更名法院命令。

如果您提供的证明合法姓名变更的文件不足以在我们的记录中识别您，或者您更改姓名已经超过两年（如果您未满18岁，则为四年前），您必须向我们出示以前姓名的身份证明文件（如我们的记录所示）。我们将接受以前姓名的有效身份证明文件。

如果您没有以前姓名的身份证明文件，我们可能会接受新姓名的有效身份证明文件，只要我们可以在我们的记录中正确确认您的身份。

身份

我们只能接受某些文件作为身份证明。例如，作为身份证明，美国社会保障局必须看到：

- 美国驾照；
- 州政府颁发的非驾照身份证件；或
- 美国护照。

如果您没有这些特定文件中的任何一个，或者在10天内无法获得其中任何一个的替代文件，我们将要求您出示其他文件。提交的所有文件，包括但不限于以下文件，必须是当前有效的（未过期），并显示您的姓名、身份信息（出生日期或年龄）和最好是近期照片：

- 员工身份证件；
- 学校身份证件；
- 健康保险卡（不是医疗保险卡）；或
- 美国军事身份证件。

注意

您的新卡将与您之前的卡具有相同的号码，但会显示您的新姓名。我们将在收到您所有信息并验证文件后尽快邮寄您的新卡。

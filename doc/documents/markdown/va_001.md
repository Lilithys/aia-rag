# 通过VA在线访问您的VA寿险政策

如果您有VA寿险，最简便的方式是在线管理您的保单。您可以使用在线门户来：

- 检查保单状态，确保其最新
- 缴纳保费（您每月支付的金额以保持保险覆盖）
- 了解您的计划和续保选项。这些将取决于您拥有的计划类型。
- 更新受益人（您选择的在您去世后从您的保单中获得资金的人）。您每年至少需要审查一次受益人信息，以确保姓名和联系方式仍然正确。如果您离婚、有了孩子或经历了其他重大生活变化，也需要审查信息并作出任何更改。

## 我如何访问我的保单？

如果您有以V、RH、J、RS、K或W开头的VA寿险保单文件号，或者您想申请因服役而致残的寿险（为因服役而致残的退伍军人提供的寿险），请通过VA在线访问您的保单。通过VA查找您的保单。

如果您有退伍军人团体寿险（VGLI）保单，并且有VGLI控制号码，请通过普尔文保险公司的办公室服务成员团体寿险访问您的保单。普尔文与我们合作，为军人和服务成员提供SGLI和VGLI福利。通过普尔文保险公司查找您的保单。

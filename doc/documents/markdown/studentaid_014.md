# 还联邦学生贷款 | 联邦学生援助

# 还学生贷款

随时都可以向学生贷款还款。从与您的联邦贷款服务提供商合作开始，以开始还款。

## 如何发送还款

您的学生贷款服务提供商负责处理您学生贷款的所有账单。如果您需要帮助进行还款，服务提供商可以与您合作。

### 向Great Lakes和Nelnet还款

我们现在接受由Great Lakes或Nelnet管理的联邦学生贷款的还款！*请访问您的账户仪表板以获取更多信息。

向Great Lakes或Nelnet还款

* 如果由于您的账户状态我们无法接受您的还款，或者您更喜欢通过服务提供商的网站进行还款，请登录您的Great Lakes或Nelnet账户。

### 向其他贷款服务提供商还款

查找贷款服务提供商的联系方式

不要错过任何还款。通过您的联邦贷款服务提供商设置自动扣款，以便您的还款自动从银行账户中扣除。

额外奖励！如果您有直接贷款，在参与自动扣款的情况下，可以享受0.25%的利率折扣！

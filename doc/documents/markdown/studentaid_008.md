# 如何更新您的FAFSA申请

新一学年，又是一个获得经济援助的机会！

免费申请联邦学生援助（FAFSA）表格适用于一个学年。这意味着您需要每年提交一次FAFSA表格，并确保满足州和学校助学金的FAFSA截止日期，以最大限度地获得援助。

## 它很容易更新您的FAFSA表格

当您登录更新您的FAFSA表格时，某些上一学年的信息会自动填充。您需要提供新的收入和税务信息，并更新任何可能更改的信息。

按照这些步骤更新您的FAFSA表格

1. 使用您的FSA ID用户名和密码登录fafsagov.gov。了解如果忘记了FSA ID用户名或密码该怎么办。
2. 选择FAFSA更新。注意：如果您通过myStudentAid移动应用以学生身份登录并且有资格进行FAFSA更新，更新后的表格会自动显示。
3. 更新任何已填充但已更改的信息，并提供所需的财务信息。
4. 签名并提交FAFSA更新。

注意：在fafsagov.gov上更新您的FAFSA表格是为了方便。您也可以选择开始一个新的FAFSA表格。

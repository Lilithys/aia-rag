# 退役军人教育援助计划 (REAP)

退役军人教育援助计划 (REAP) 于2015年11月25日结束，但根据2016年国防授权法案，某些REAP福利将在未来三年内继续存在。了解此更改对您意味着什么。

## 这对我有什么影响？

请找到以下描述中最符合您情况的描述，以了解此更改如何影响您以及下一步该怎么做。

### 如果您在2015年11月24日或之前正在使用REAP福利

您可以继续使用您的REAP福利直到2019年11月25日。

注意：如果您在2015年11月24日或之前已经开始上学或参加培训项目，或者在该日期前的最后一学期、季度或学期结束前已经开始，那么您符合此描述。

### 如果您申请了REAP福利，但您直到2015年11月24日之后才开始上学

您不再有资格获得REAP福利，但您可能有资格获得《9/11后退伍军人法案》福利。了解《9/11后退伍军人法案》

### 如果您在2015年11月24日之后申请了REAP福利

您没有资格获得REAP福利，但您可能有资格获得《9/11后退伍军人法案》福利。我们将审查您的申请并为您提供您有资格获得的福利。了解《9/11后退伍军人法案》

### 如果我们在计划结束时确定您有资格获得REAP福利，但您在计划结束时失去了这些福利

如果您满足以下两个要求中的所有要求，您可以将您的REAP资格计入《9/11后退伍军人法案》资格。

这两个条件都必须为真。您：

- 在2015年11月25日之前建立了REAP资格，
- 在2015年11月25日我们退役该计划时失去了资格

如果您将您的资格计入《9/11后退伍军人法案》资格，您：

- 将获得相当于剩余REAP福利月份（或部分月份）的《9/11后退伍军人法案》福利，最多36个月
- 将不再有资格获得基于您之前的REAP资格和《9/11后退伍军人法案》新资格的48个月的权益
- 将有资格获得《9/11后退伍军人法案》60%的支付级别，无论您的《9/11后退伍军人法案》服役时间长短

如果您想切换您的福利，请拨打888-GI-BILL-1（888-442-4551），周一至周五上午8:00至下午7:00东部时间。

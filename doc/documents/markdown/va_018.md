# VA服装补助

你的衣物是否因假肢或矫形装置（如轮椅）或皮肤状况药物的使用而受损？如果是这样，你可能每年可以获得一笔钱来购买新衣物。这是一项残疾补偿福利，被称为年度服装补助。了解你是否可以获得这项福利。

### 我可以从VA获得残疾福利吗？

如果你满足以下列出的两个条件之一，你可能可以获得残疾福利。

这两个条件都必须为真：

- 你的假肢或矫形装置或皮肤药物导致衣物损坏，
- 你需要这种装置或皮肤药物是因为与军事服务相关的伤残或疾病（称为与军事服务有关的条件）

### 谁可以被覆盖？

退役军人

## 你可以获得哪些残疾福利？

- 一次性支付，
- 年度支付

注意：当前的服装补助率为817.48美元。

查看特殊补助的当前费率

## 我如何获得这些福利？

你需要提交残疾补偿申请。了解如何提交残疾补偿申请。

当你提交残疾索赔时，还需要填写此附加表格：

年度服装补助申请表（VA表10-8678）下载VA表10-8678（PDF）

把它带到你当地的VA医疗中心的假肢代表那里。

要在当年获得年付，您必须在当年的8月1日前符合条件。如果您满足以下列出的至少一项要求，您可能能够获得多于一个支付。

至少必须满足以下条件之一：

- 您拥有多于一个假肢或矫形装置，或
- 您拥有多于一种皮肤药物，和/或
- 您的装置或皮肤药物影响了多种类型的衣物。

# 经销商和运输商的一般信息

重要：自2018年夏季起，经销商记录保存将有新的规定。[1]

最佳的信息来源是纽约州经销商及运输商条例（PDF）[2]（CR-78）.

### 以现状售出零售车辆

某些例外情况允许您使用残损车辆证书（MV-907A）将车辆以“废品”出售。DMV不能为废品车辆或修复后的残损车辆颁发车辆证书或注册，除非该车辆通过了残损车辆检查。如果颁发了车辆证书，该证书将带有“REBUILT SALVAGE:NY”的标识.

### 零售销售证书（MV-50）上的售价，如果我批发出售车辆

当车辆批发出售时，售价无需填写在零售销售证书（MV-50）上.

### 出租车籍地为外州的客户需要进行检查

对于注册在其他州的车辆，不需要进行纽约州的车辆检查.

### 至少行驶了110,000英里且售价为1,295美元的车辆的保修

这些条款指的是纽约州司法厅（网址：www.ag.ny.gov[3]）在‘柠檬法’中描述的保修条款。车辆及交通法要求经销商在零售销售证书（MV-50）上完成二手车认证。该法律适用于所有以任何价格销售且里程表显示任何里程数的车辆。车辆在销售时必须适合上路使用.

### 临时注册即将到期

如果您无法为售出的车辆获取车辆证书，且临时注册即将到期，您将无法获取另一份临时注册。根据DMV委员条例，如果您没有所有权证明，不得出售车辆。在任何情况下，您都不能在任何情况下颁发额外的临时注册.

### 保证书

要获取保证书，您必须联系保证保险公司。确保保证书上的企业名称和邮寄地址与您的DMV设施许可证上的名称和地址完全一致。确保您在保证书上写明您的设施编号.

# 学习驾驶许可限制

无论你的年龄多大，如果你持有学习驾驶许可，除非有年满21岁或以上且持有有效驾照的监督驾驶员陪同，否则你不得驾驶。例如，只有持有摩托车驾照的人才能监督学习驾驶摩托车的人。1

你不得持学习驾驶许可驾驶

- 在纽约市的任何公园内的街道
- 由布鲁克林-布鲁克林-亨利桥和隧道管理局管辖的任何桥梁或隧道
- 西彻斯特县的交叉县、赫歇尔河、萨姆河或塔科因州立公园大道
- 在DMV道路测试区域

### 未满18岁？

如果你未满18岁或是你未满18岁的驾驶员的家长，了解逐步驾照法（GDL）和未满18岁驾驶员的限制非常重要。[1]

### 我在获得学习驾驶许可后多久可以参加路考？

如果你未满18岁，你必须在获得学习驾驶许可后的至少6个月后才能预约路考。

- 1.

如果你持有摩托车学习驾驶许可（类别M、MJ或有限MJ），你的监督驾驶员必须：

- 在你操作摩托车时进行一般监督，并
  - 保持在你前方四分之一英里以内，随时保持视线接触

你只能在摩托车上搭载你的监督驾驶员作为乘客。如果你持任何有效类别的学习驾驶许可驾驶摩托车，同样的乘客规则适用。

# 有关帝国黄金车牌的信息 [1]

自2010年4月1日起，DMV开始发行帝国黄金车牌。DMV不再发行帝国蓝白车牌。

### 无需在续签时更换帝国黄金车牌

您可以保留现有的车牌或订购帝国黄金车牌。

### 何时可以申请帝国黄金车牌

您将在以下情况下获得帝国黄金车牌：

- 申请更换丢失或被盗的车牌
- 申请新车注册且不从另一辆车转移车牌或注册
- 订购个性化车牌

您可以在以下情况下订购帝国黄金车牌：

- 在线、邮寄或DMV办公室续签时 [2]
- 更换现有车牌（当注册未到期续签时）

### 如何订购

您可以通过电话、在线或在DMV办公室订购帝国黄金车牌。新车牌和注册文件将分别通过邮寄送达。通常情况下，您会先收到新的注册文件，然后再收到您的车牌。

为了避免交通罚单，请即使新注册文件尚未到达，也要将新注册文件放在车上。一旦收到新车牌，应立即安装。

在线订购时，您必须提供：

- 车牌号码
- 车辆类别
- 您的姓名
- 您的ZIP码（DMV记录中）

在线订购帝国黄金车牌 [4]

### 费用

您必须支付车牌费用为

- 两盘装25美元
- 单盘装12.50美元（例如摩托车、拖车等）

- 你可能需要支付额外费用。如果你的注册不需要续期，更换车牌的费用是3.75美元。

### 维持相同的车牌号码

如果你的车辆注册在以下类别之一，你可以支付额外的20美元费用，从而在新的帝国黄金车牌上保留你当前车牌的号码。

- 客车（PAS）
- 商用车（COM）
- 摩托车（MOT）
- 拖车（TRL）
- 其他特定注册类别 - 请查看可保留号码的注册类别列表 [5]

### 车牌费用

当你续期时不需要获取新的帝国黄金车牌，也不需要支付车牌费用，你可以续期并保留当前的车牌。

如果你需要新的车牌，或者选择获取新的帝国黄金车牌，你需要支付车牌费用。

- 两盘装的费用是25美元
- 单盘装的费用是12.50美元

当你没有续期注册时，订购帝国黄金车牌时，还有额外的3.75美元车牌交易费用。

### 我有个性化车牌。如果我申请帝国黄金车牌，我可以保留相同的车牌号码吗？

可以。当你续期注册时，你可以获取新的帝国黄金车牌并保留你的个性化车牌号码。

除了续期费用外，你还需要支付新的车牌费用（两盘装25美元，单盘装12.50美元）。因为你目前支付年度个性化车牌费用，所以不会收取额外的费用来保留相同的号码。

如果你的注册不需要续期，但你想订购帝国黄金个性化车牌来替换你当前的个性化车牌，你可以在网上或DMV办公室订购帝国黄金车牌。当你没有续期注册时，订购帝国黄金车牌还有额外的3.75美元车牌交易费用。

### 你应该如何处理旧的帝国蓝白车牌

当你收到新的帝国黄金车牌时，不要将旧的车牌退回DMV。根据当地指南回收旧的车牌。

为了获取全州范围内的当地回收协调员列表，请访问纽约州环境保护部的网站 http://www.dec.ny.gov/chemical/8511.html [6]。

在回收旧的车牌之前，使用永久性墨水标记划掉车牌号码或其他方式损坏车牌。为了你的安全，分开放置并分别在不同的周将车牌放入回收箱。

# 联邦 versus 私人贷款 | 联邦学生援助

# 在支付大学、职业学校或研究生院的费用时，联邦学生贷款可以为私人学生贷款提供几种优势。

需要贷款来帮助支付大学费用吗？先考虑联邦贷款！

如果你申请了经济援助，你的学校很可能会将学生贷款包含在你的经济援助包中。了解你被提供的贷款类型很重要。通常，有两种类型的助学贷款：联邦和私人。

- 联邦学生贷款和联邦家长贷款：这些贷款由联邦政府资助。
- 私人学生贷款：这些贷款是非联邦贷款，由银行、信用合作社、州机构或学校等贷款人提供。

## 如果你需要借款来支付大学或职业学校的费用，请先考虑联邦贷款。

联邦学生贷款是

- 直接补贴贷款和直接非补贴贷款
- 直接父PLUS贷款（针对研究生和专业学生）。

联邦家长贷款是

- 父PLUS贷款（针对家长）。家长完全负责支付这些贷款，即使这些贷款是为学生利益而申请的。

## 联邦和私人学生贷款之间有什么区别？

联邦学生贷款由政府提供，条款和条件由法律规定，包括许多好处（如固定利率和收入驱动的还款计划），这些通常不是私人贷款提供的。

相比之下，私人贷款由银行、信用合作社和州立或州立附属机构等私人组织提供，条款和条件由贷款人设定。私人学生贷款通常比联邦学生贷款更昂贵。

## 我如何获得联邦学生贷款？

要获得联邦贷款，你必须首先填写《联邦学生援助免费申请表》（FAFSA）。了解更多关于申请援助的信息。

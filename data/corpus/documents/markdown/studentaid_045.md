# 申请财政援助

申请联邦助学金、勤工助学和大学贷款最关键的一步是填写联邦学生援助免费申请表（FAFSA）。

# 援助申请流程

按照以下步骤申请联邦学生援助。

# 01

## 准备

收集你需要的文件。

# 02

## 填写FAFSA表格

尽早申请以最大化你的援助。

# 03

##

查看学生援助报告

如有必要，进行更正。

# 04

## 回应援助通知

接受你想要的援助。

# 05

## 领取援助

从你的学校获取援助。

# 06

## 续签你的FAFSA表格

每年重新申请。

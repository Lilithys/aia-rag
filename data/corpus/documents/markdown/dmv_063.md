# 关于交易条目（transaction entries）的信息

### ZIP Code 和 Email 条目

注意：如果您的地址已更改，请勿在线处理交易。相反，请按照说明更改您的地址 \[1\]。

您无法在在线交易期间更新您的地址。DMV 网站上有关于在 DMV 文件和记录上更改姓名的说明 \[2\]。

当前 ZIP Code。请输入您当前邮寄地址的 ZIP Code。要使用此在线交易，您的 ZIP Code 必须

- 与您 DMV 记录上的 ZIP Code 匹配
- 是美国 ZIP Code

所有邮件均寄往您 DMV 记录上的地址。请参阅如何更改您 DMV 车辆记录和文件上的地址 \[1\]。

您的 Email 地址。请输入有效的 email 地址，并重新输入 email 地址以进行验证。DMV 将通过 email 向您发送交易确认。

您的 email 程序必须能够接收来自包含域名 dmv.ny.gov 的地址的邮件。如果您需要帮助，请参阅有关 email 地址的信息 \[3\]。

### 驾驶执照信息

DMV ID 号码。这是打印在您的驾驶执照、学习许可证或非驾驶员 ID（DMV 照片文件）上部的 9 位“ID”号码。仅输入 9 位数字；不要输入空格、连字符或其他标点符号。请参阅驾驶执照文件样本 \[4\]。

姓名。请按照您的 DMV 照片文件或其他 DMV 文件（如驾驶记录摘要、吊销或暂停令或与您的驾驶执照相关的信函）上显示的姓名，输入您的姓氏、名字和中间首字母。如果您不确定您的姓名如何显示，请按照以下规则输入您的姓名。

- DMV 记录上的姓名以大写字母显示，并在在线交易中以大写字母显示
- 仅输入字母
- 不要输入数字
- 后缀应以罗马数字输入（例如“SMITH III, JOHN, A.”）
- 不要输入空格或特殊字符，如逗号或撇号（如果您的 DMV 记录上的姓名包含连字符，则可以输入连字符 - 例如，将姓名 O'Brien 输入为 OBRIEN）

文件号码。文件号码为 8 或 10 个字符，打印在您的 DMV 照片文件的右下角，或背面（对于 2014 年 1 月 29 日之后签发的文件）。8 字符格式全为数字。10 字符格式为字母和数字。字母字符为大写。请参阅驾驶执照文件样本 \[4\]。

出生日期。输入两位月份、斜杠、两位日期、斜杠和四位年份。例如，1964 年 5 月 2 日输入为 05/02/1964。

SSN 后四位。请输入您的社会安全号码的后四位。此信息仅用于帮助识别您的交易身份。请参阅隐私与安全声明 \[5\]。

### 注册续期输入说明

车辆牌照或船只注册号码。请输入您的注册续期通知或注册文件上的车辆牌照号码或船只注册号码。仅输入字母和数字；不要输入空格、连字符或其他特殊字符。

对于船舶注册号，请排除文件中可能出现的字母"NY"。仅输入另外两个字母和四个数字。

如需帮助，请参阅示例注册文件\[6\]。

输入字母O或数字0（零）时，请确保输入正确的字符。字母O看起来会比数字零更宽。

注册类别代码。请输入注册文件中的三位字母注册类别代码。如需帮助，请参阅示例注册文件\[6\]。船舶的注册类别代码为BOT。

### DMV记录地址的输入

纽约州法律要求您在10天内向DMV报告居住地变更。

当您在线提交邮寄地址变更时，如果DMV没有您的居住地址记录，您必须输入居住地址。您的居住地址不能是邮政信箱。

如果您在DMV已有居住地址记录，更改邮寄地址时无需更改居住地址，但您可以根据需要更改居住地址。

您的居住地址不必与邮寄地址相同，但您可以选择将邮寄地址作为居住地址。

如果您向美国邮政服务（USPS）报告地址变更，这不会更改您在DMV记录中的地址，但您可以在本次交易中输入新的USPS地址（国家地址变更或NCOA地址）。

当您在DMV更改地址时，它

- 不会更改您在DMV记录中的地址，除非是您选择在交易中更改的驾驶执照/DMV照片文件记录和/或注册记录（例如，在DMV更改地址不会更改交通罚单记录上显示的地址）
- 如果您在交易中为某注册选择了"无变更"，则不会更改该注册记录上的地址
- 不会更改您在美国邮政服务（USPS）或其他任何DMV指定记录之外的地址
- 不会生成带有您新地址的新文件（提交在线地址变更后，您可以更换驾驶执照、许可证或非驾驶员ID\[7\]和/或更换显示新地址的注册文件\[8\]）

当您在线提交地址变更时，该变更仅适用于您选择的DMV记录。在线地址变更应用程序会显示DMV在您名下找到的驾驶执照、许可证或非驾驶员ID（DMV照片文件）和注册记录。如果您的名下还有未显示的注册，您可以输入车牌号或注册号将其添加到列表中，并更改这些注册的地址。

如果您在地址变更列表中对任何照片文件或注册选择了"无变更"，您为其他DMV记录输入的新地址将不适用于这些记录。如果您想将这些记录的地址更改为不同的新地址，则必须处理单独的地址变更，并仅选择应用该地址的记录。

如果地址变更列表中的驾驶执照、非驾驶员ID或注册符合续期条件，处理地址变更后，到期日将在确认页面上以粗体红色文本显示。然后您可以上网续期您的照片驾驶执照或非驾驶员照片ID卡\[9\]、续期车辆注册\[10\]或续期船舶注册\[10\]，并收到显示新地址的文件。

地址变更处理完成后，会提供链接以订购显示新地址的补发（副本）文件。订购补发文件需支付费用。

### 在线手册订单

大多数DMV手册可通过DMV出版物\[11\]页面在线获取。这包括在线驾驶员手册和带测验的学习指南\[12\]。

DMV 驾驶员手册的单份打印版也可在 DMV 办公室 [13] 免费获取，或通过您所在区号的 DMV 呼叫中心 [14] 邮寄索取。

对于公共或私人组织的大批量手册订购，请使用在线 DMV 手册订购交易 [15]。

- 对于公共组织（定义见下文），批量订购不收取费用
- 对于私人组织（定义见下文），批量订购每本手册收费 1.00 美元，且最低订购量为 25 本

公共组织和私人组织的定义如下

定义

公共组织（public organization）的定义为

- 属于州、县或市的一个部门（division）的组织
- 根据州或地方法律的规定设立或组建
- 可以直接征税或由政府资助（例如：公立学区、公共图书馆、BOCES）

私人组织（private organization）是指这样的企业，它

- 不属于州、县或市的一个部门（division）
- 不是根据州或地方法律的规定设立或组建
- 不能直接征税或由政府资助（例如：商业驾驶学校、PIRP 赞助商、安全倡导团体等）

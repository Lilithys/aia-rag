# 完成财政援助流程

你已经完成了最重要的任务——提交联邦学生援助免费申请（FAFSA）表格。了解接下来需要做什么。

# 后续步骤

财政援助流程中还有几个步骤。

# 01

## 了解信息

了解援助是如何计算的。

# 02

## 比较援助方案

查看学校的财政援助方案。

# 03

## 回复援助方案

接受所选学校的援助。

# 04

## 签署贷款协议

完成*主本票*（MPN）。

# 05

## 完成入学咨询

在获得第一笔贷款或TEACH助学金之前，完成咨询。

# 获取你的资金

## 你的学院或职业学校，而非美国教育部，将发放你的经济援助。

了解你的学校何时支付你的援助，以及每笔支付涵盖的时期。

了解如果课程开始时你尚未获得经济援助，如何支付教材费用。

了解你将如何获得援助——这完全取决于你获得的援助类型。

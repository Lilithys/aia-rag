# 了解获取社会保障卡所需文件 | 社会保障管理局

### 美国出生儿童的更正卡

如果您因收养、法院命令或任何其他原因合法更改孩子的姓名，您需要告知社会保障局，以便获得更正卡。如果您的孩子有工作，也请告知孩子的雇主。如果您未在孩子姓名变更时告知我们，可能会导致：

- 延迟您的退税或孩子的退税；以及
- 阻止孩子的工资正确记入其社会保障记录，这可能会降低孩子未来社会保障福利的金额。

重要提示

您必须出示原始文件或由签发机构认证的副本。我们不接受复印件或公证副本。所有文件必须是最新的（未过期）。我们不接受显示您已申请该文件的收据。

### 我需要哪些原始文件？

公民身份

如果您尚未向我们证明您子女的美国公民身份，我们需要查看美国公民身份的证明。我们只接受特定文件作为美国公民身份的证明。这些包括美国出生证明或美国护照。

重要

本文件仅在您的孩子尚未与我们建立公民身份时才需要提供。

姓名变更

如果您需要更改孩子社会保障卡上的姓名，您必须向我们出示孩子合法姓名变更的证明。社会保障局可能接受以证明孩子合法姓名变更的文件包括：

- 载有新姓名的最终收养判决书；
- 法院批准姓名变更的命令；或
- 载有新姓名的修正版出生证明。

如果您提供的孩子合法姓名变更证明文件未能提供足够信息，使我们在记录中识别您的孩子，或者您更改孩子姓名的日期已超过四年，您必须向我们出示孩子先前姓名（即我们记录中显示的姓名）的身份证明文件。我们将接受已过期的、使用孩子旧姓名的身份证明文件。

如果您没有孩子先前姓名的身份证明文件，只要我们能妥善确认孩子在记录中的身份，我们可能接受使用孩子新姓名的未过期身份证明文件。

身份

您的孩子：我们仅接受特定文件作为孩子身份的证明。可接受的文件必须显示孩子的姓名、身份识别信息（即年龄、出生日期或父母姓名），并最好附有近期照片。通常，如果非照片身份证明文件包含足够信息以识别孩子（如孩子姓名和年龄、出生日期或父母姓名），我们也可以接受。我们更倾向于查看孩子的美国护照。如果该文件不可用，我们可能接受孩子的：

- 州政府签发的非驾照身份证；
- 收养令；
- 医生、诊所或医院记录；
- 宗教记录；
- 学校日托中心记录；或
- 学校身份证。

您：我们还必须查看您的身份证明。可接受的文件必须是当前有效的（未过期），并显示您的姓名、身份信息（出生日期或年龄），最好附有近期照片。例如，作为身份证明，Social Security 必须查看您的：

- 美国驾照；
- 州政府签发的非驾照身份证；或
- 美国护照。

如果您没有这些特定文件之一，或者无法在10天内获得其中一份文件的补发件，我们将要求查看其他文件。提交的任何文件，包括以下文件，必须是当前有效的（未过期），并显示您的姓名、身份信息（出生日期或年龄），最好附有近期照片：

- 员工身份证；
- 学校身份证；
- 健康保险卡（不是 Medicare 卡）；或
- 美国军人身份证。

注意

您孩子的新卡将具有与您孩子之前的卡相同的号码，但会显示新姓名。一旦我们拥有您孩子的所有信息并核实了您孩子的文件，我们将尽快邮寄您孩子的卡。

# 将纽约州驾照更换为非驾驶员ID卡 \[1\]

您可以将当前有效或过期不超过2年的纽约州驾照或学习驾照更换为纽约州非驾驶员ID卡（NDID）。

您必须通过邮寄或在DMV办公室办理。

### 在办公室办理并升级为Enhanced或REAL ID

您不必办理Enhanced或REAL ID。1 但是，如果您持有Standard，从2020年10月起将不允许登机国内航班（除非您有护照）。如果您计划旅行，我们建议您现在就来DMV，避免第二次办公室访问。了解更多关于Enhanced、REAL ID和Standard文件的信息 \[2\]。

完成此指南，确保您在来DMV之前有所需的身份证明。选择“Replace, Renew, or Change my existing NY State License/ID to REAL ID or Enhanced”选项。

查找您的证明 \[3\]

### 通过邮寄

* *重要提示：** 如果您持有Standard，在2020年10月1日之后，它将不被接受为登机国内航班的身份证明（除非您有护照）。**我们建议您来DMV升级为Enhanced或REAL ID。** 按照上述在办公室办理的说明操作。

#### 邮寄

- 填写完整的Application for Permit, Driver License or Non-Driver ID Card（PDF） \[4\] （MV-44）
- 您的驾照或学习驾照（必须当前有效或过期不超过两年）
- 您的Supplemental Security Income证明的复印件，如果要求（见下文）- 请勿邮寄您的原始文件
- 按下表所示支付费用

#### 邮寄至

DMV License Production BureauP.O. Box 2688 ESP Albany, NY 12220-0668

通过快递服务

DMV License Production Bureau Room 424A, 6 Empire State Plaza Albany, NY 12228

### 费用

了解更多关于Standard、REAL ID和Enhanced文件的信息 \[5\]。

### 补充保障收入（SSI）证明

要证明您领取SSI，您必须携带以下列出的文件之一前往DMV。文件必须是原件，不能是复印件。

- 通知您符合SSI福利资格的通知书
- 生活费用调整（COLA）信函
- 付款变更通知（SSA-L8151）
- 第三方查询（TPQY）信函
- 保密社会保障信息报告（SSA-2258）
- 福利核实信（您必须提前致电社会保障局获取此信：1-800-772-1213）

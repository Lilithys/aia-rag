# 提供保险证明

## 提供保险证明 [1]

如果您的驾驶执照或车辆注册因汽车责任保险覆盖中断而被吊销，您可以通过在线或邮寄方式提供 您现在已投保的证明。

在您提供保险证明后，DMV 将与您的保险公司核实您的保险覆盖情况。1

您可以在线查看您的保险状态 [2]。您也可以通过 MyDMV [3] 查看您的驾驶执照和车辆注册状态。2

如果您需要书面确认 DMV 已解除吊销或撤销，您必须订购您的驾驶记录或车辆摘要。3

### 在线办理

要在线提供证明，您在 DMV 记录中的姓名和地址必须正确。

您需要

- DMV 发出的查询或吊销令（参见示例 [4]），其中包含

- - 车辆牌照号

- - 10 位文件编号

- NY State 保险身份证（参见示例保险卡 [5]），其中包含

- - 您的责任保险覆盖生效日期

- - 您的责任保险保单号

- - 您的保险公司的 3 位代码

您的记录更新可能需要 48 小时。

在线提供保险证明 [6]

邮寄办理

请将您的保险信函的底部部分（撕条）和您的 NY State 保险身份证（清晰的复印件可接受）邮寄至

NYS Department of Motor Vehicles Financial Security Bureau PO BOX 2725 Albany NY 12220-0725

您的保险身份证上的姓名和车辆信息必须与您的车辆注册信息一致。

您无法通过电话或在 DMV 办公室提供证明。

- 1. 如果您的保险公司未核实或否认您提交的信息，您的驾驶执照和/或车辆注册将被或将继续被 吊销或撤销。

- 2. 要创建 MyDMV 账户，您需要您的 NY State 驾驶执照、学习许可证或非驾驶员 ID 卡以及您社会安全号码的最后 4 位数字。

- 3. 您可以通过 MyDMV [3] 订购并立即下载您的驾驶记录摘要。要创建 MyDMV 账户，您需要您的 NY State 驾驶执照、学习许可证或非驾驶员 ID 卡以及您社会安全号码的最后 4 位数字。要获取您的车辆注册摘要副本，请使用 Request For Driving and/or Vehicle Record Information (PDF) [7] (MV-15)。

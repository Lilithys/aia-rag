# 护航驾驶员认证

# 护航驾驶员认证 [1]

### 我何时需要持有护航驾驶员认证？

在以下情况下，护航驾驶员认证是强制性的

- 您在纽约州高速公路上护送超限货物 1
- 您担任超限货物的旗手

在以下情况下，护航驾驶员认证不是强制性的

- 您护送的超限货物低于脚注\#1中所述的要求
- 您是军人并护送军事车队
- 您护送州政府车辆

### 提供护航服务的资格要求是什么？

要成为合格的认证护航驾驶员，您必须

- 年满21岁或以上
- 持有有效的纽约州驾驶执照或您居住的州或司法管辖区颁发的有效驾驶执照 2
- 通过护航驾驶员认证考试

### 我如何获得护航车辆驾驶员认证？

要获得护航车辆驾驶员认证

- 前往提供护航驾驶员认证考试的DMV办公室
- 填写车辆护航驾驶员申请表（PDF）[2]（MV-65）
- 参加笔试 3

您无需预约即可参加考试。但是，并非所有DMV办公室都提供该考试。请致电您计划参加考试的DMV办公室，以确保该地点提供该考试。如果您持有纽约州驾驶执照，前往办公室参加考试时必须携带。如果您持有其他州签发的驾驶执照，则必须携带有效的驾驶执照和额外的身份证明前往办公室。有关可接受额外身份证明的更多信息，请参阅DMV文件指南 [3]。

通过考试所需的所有信息均包含在交通部认证护航手册（PDF）[4]中。

您还应熟悉纽约州驾驶员手册 [5]。

如果您通过考试，您将立即获得提供超限货物护航服务的认证。您将获得一份为期60天的临时护航驾驶员证书。您的永久证书将通过邮件寄送。提供护航服务时，您必须随身携带该证书。

### 费用是多少？

参加车辆护送考试的費用为40.00美元。支票抬头必须写明支付给机动车管理局局长。初次认证不收取额外费用。

如果您未通过笔试，可以再次参加。每次参加考试的费用为40.00美元。

### 我的护送车辆认证何时到期，以及如何续期？

如果您持有纽约州驾驶执照，您的护送驾驶员证书将与驾驶执照同时到期。如果您持有其他州的驾驶执照，您的证书自签发之日起有效期为四年。

您将通过邮件收到续期通知。请按照续期通知中的说明续办您的护送驾驶员证书。请记住保持您的邮寄地址在纽约州DMV的最新状态。

如果您在到期日期后两年内未续期认证，您将需要重新参加并通过笔试，之后才能重新获得认证。

### 如果我需要更改地址或姓名，该怎么办？

如果您持有纽约州驾驶执照，您必须在十天内更改您的地址[6]或姓名[7]。巴士驾驶员部门无法为您进行更改。

如果您持有其他州签发的驾驶执照，您必须在十天内书面通知DMV的巴士驾驶员部门。请将您的DMV ID号码（客户ID号码）（位于您的护送证书上）、以前的地址或姓名以及您的新地址或姓名发送至：

纽约州机动车管理局巴士驾驶员部门客户服务部6 Empire State Plaza, Room 136B Albany, NY 12228

### 如果我需要更换证书，该怎么办？

如果您的车辆护送卡丢失、被盗或损毁，您可以写信给DMV申请更换。您必须发送您的姓名、地址和DMV ID号码（客户ID号码）（位于您的护送证书上）（如有）。请将您的请求以及一张5美元的支票或汇票（抬头写明支付给机动车管理局局长）发送至：

纽约州机动车管理局巴士驾驶员部门客户服务部6 Empire State Plaza, Room 136B Albany, NY 12228

### 如果我的驾驶执照被吊销或暂停，我的护送车辆认证仍然有效吗？

不。如果您的驾驶执照或驾驶特权在签发管辖区被吊销或暂停，或者您已失去在纽约州的驾驶特权，您的护送证书无效。

您的认证也可能被取消，如果

- 违反安全护送程序或NYCRR（纽约州法典、规则和条例）第17篇第154部分
- 您身体上、精神上或医疗上无法驾驶
- 您在申请护送驾驶员认证时提供虚假或欺诈信息

根据违规的性质，驾驶员可能面临罚款和处罚。4

### 纽约州是否承认其他州颁发的护航车辆驾驶员认证？

不可以。要在纽约州合法驾驶护航车辆，您必须持有有效的纽约州认证车辆护航卡（MV-64）。在纽约州驾驶护航车辆时，您必须随身携带MV-64卡和驾驶执照。

- 1. 这些是指宽度超过12英尺、长度达到或超过80英尺、高度达到或超过14英尺的负载。还包括负载/车辆超出主体部分超过10英尺的悬伸负载。
- 2. 没有当前纽约州驾驶特权的外州驾驶员不符合护航认证资格。
- 3. 您将在DMV办公室收到考试表格。不允许携带笔记、手册和其他学习材料。管理考试的DMV工作人员不得讨论问题或提供任何帮助。
- 4. 参见纽约州车辆与交通法和/或纽约州法规、规章第17篇第154部分和/或纽约州法规、规章第21篇第102部分。

## 在DMV办理：

您必须在DMV办公室申请护航驾驶员认证 [8]。

并非所有DMV办公室都提供该考试。如果某个办公室提供认证考试，将在该办公室的“办公时间”区域中注明。

# CHAMPVA倡利|退伍军人事务音

## CHAMPVA福利

您是否是因残疾或已故退伍军人的配偶、在世配偶或子女?如果您不符合TRICARE (国防部为现役和退役军人家属提供的医疗保健计划)的资格，您或许可以通过退伍军人事务部民事健康与医疗计划( CHAMPVA )获得健康保险。通过该计划，我们承担您部分医疗保健服务和用品的费用。这称为费用分挫。了解您是否符合CHAMPVA资格以及如何申请。

## 我能否通过CHAMPVA获得医疗保健?

只有您不符合TRICARE资格，并且以下描述中至少有一项适用于您，您才能通过CHAMPVA获得医疗保健。以下至少一项必须属实。您是:

-由VA地区福利办公室评定为因服役相关残疾而完全且永久残疾的退伍军人的配偶或子女,或

-因VA评定的服役相关残疾去世的退伍军人的在世配偶或子女,或

-去世时被评定为因服役相关残疾而完全且永久残疾的退伍军人的在世配偶或子女,或

-在执行任务中因非不当行为去世的军人的在世配偶或子女(在大多数此类情况下，家庭成员符合TRICARE资格,而非CHAMPVA )。服役相关残疾是指我们认定由退伍军人的现役服役引起或加重的残疾。永久残疾是指预计不会改善的残疾。注意:作为家庭合格CHAMPVA赞助人的退伍军人也可能根据其自身的退伍军人身份符合VA医疗保健计划的资格。如果两位配偶都是退伍军人,且均符合作为家庭CHAMPVA赞助人的资格,那么他们现在都可能符合CHAMPVA福利的资格。每次他们需要医疗护理时,可以选择通过VA医疗保健计划或使用其CHAMPVA保险获得护理。

## 还有哪些因素可能影响我或家人获得CHAMPVA福利?

还有其他因素可能影响您或其他家庭成员是否符合CHAMPVA资格。请点击与您情况相符的描述以了解更多:

-如果您正在期待宝宝出生，您需要在为新生儿申请CHAMPVA之前完成以下两个步骤。您需要:

-前往最近的社保管理局办公室为您的宝宝申请社会安全号码，并且

- -联系最近的VA地区福利办公室,将宝宝的身份设置为退伍军人赞助人的受抚养人。

在您将宝宝加入CHAMPVA之前，医疗索赔无法支付，因此请尽快为宝宝获取社会安全号码并将其身份设置为受抚养人。查找附近的社保管理局办公室查找附近的VA地区福利办公室

-如果您是合格CHAMPVA赞助人的在世配偶，并且在55岁之前再婚,您将从再婚日期午夜起不再符合CHAMPVA资格。如果您在55岁生日当天或之后再婚，您可以保留您的CHAMPVA柱利。

-如果您是符合资格的CHAMPVA先助人的未再婚配偶，并且您再婚,但再婚因死亡、离婚或宣告无效而结束，您可能再次符合CHAMPVA的资格。您再次符合资格的第一个日期是您再婚结束后的下个月第一天或1999年12月1日,以较晚者为准。您需要向我们提供您的结婚证书以及死亡、离婚或宣告无效文件的副本(视情况而定)。

-如果您在CHAMPVA保障范围内且年满18岁,您需要向我们发送您全日制就读于大学或其他教育机构的证明,以继续获得柱利。下载我们关于CHAMPYVA福利的学校注册认证要求的情况说明书( PDF )

-如果您作为退伍军人的继子女在CHAMPVA保障范围内，并且您因离婚或再婚而离开退伍军人的家庭，您将不再符合CHAMPVA的资格。

-如果您是照顾残疾退伍军人的家庭成员，并且您无权通过其他健康计划获得护理或服务，您可能符合CHAMPVA的资格。下载关于主要家庭照顾者的CHAMPVA情况说明书( PDF )获取更多关于主要家庭照顾者的CHAMPVA信息如果您所照顾的退伍军人在2001年9月11日或之后在执行任务时受重伤,您可能通过综合家庭照顾者援助计划获得医疗保健福利和其他照顾者支持。了解您是否符合此计划的资格以及如何申请

- CHAMPVA始终是Medicare的第二支付方。以下是您需要了解的一些要求:如果您未满65岁，并且满足以下两项要求，您就有资格获得CHAMPVA。以下两项都必须属实。您:

-同时拥有Medicare A部分和B部分，并且

- -在其他方面符合CHAMPVA的资格如果您年满65岁或以上，并且有资格获得Medicare，您就有资格获得CHAMPVA。如果您在2001年6月5日之前年满65岁,，并且您有权享受Medicare A部分或B部分,您还需要注册Medicare B部分才能符合CHAMPVA的资格。

注意:您无需注册Medicare D部分即可符合CHAMPVA的资格。下载关于Medicare和CHAMPVA的情况说明书( PDF )

# 通过CHAMPVA我能获得哪些福利?

通过CHAMPVA ,当我们确定服务或用品在医学上是必要的并且由授权提供者提供时，您将获得保障。当提供者在其执照或认证范围内提供服务时，我们认为他们是授权的。承保服务包括:

-救护车服务

-门诊手术

-耐用医疗设备( DME )

-计划生育和孕产

-临终关怀

-住院服务

-心理健康服务

-门诊服务

-药房(处方药)

-专业护理

-器官移植当您注册CHAMPVA后，您特收到一份CHAMPVA计划指南。该指南将向您详细介绍承保和不承保的服务及用品。

-下载CHAMPVA计划指南( PDF )

-查看CHAMPVA政策手册中不承保的服务和用品的完整列表

-下载关于CHAMPVA柱利的情况说明书

# 我如何获得CHAMPVA柱利?

您需要申请这些福利。要申请，请提交以下所需文件:

- CHAMPVA柱利申请表( VA表格10-10d ) ( PDF )，以及

-其他健康保险认证( VA表格10-7959c )，以及

-与您的Medicare状态相关的文件:

-如果您因任何原因符合Medicare资格，您需要提交您的Medicare卡副本。

-如果您年满65岁或以上且不符合Medicare资格，您需要向我们发送社会保障管理局的文件，确认您不符合任何人社会保障号下的Medicare柱利资格。为加快您的申请处理,您还可以发送这些可选文件的副本(非原件) :

- VBA评级决定中显示您的退伍军人完全且永久残疾(或如果您是遗属，则为死亡评级)的页面

-您的退伍军人的DD214 (现役释放或退伍证书)，或者如果退伍军人是二战或朝鲜战争退伍军人,则为分离报告。如果您没有所需表格的副本，您可以通过向国家档案馆提交标准表格180 (军事记录请求)来索取。了解如何通过在线、邮寡或传真方式请求军事服务记录

-与您申请中包括的任何受抚养子女相关的文件:

- -每个子女的出生证明或收养文件副本18-23岁子女的全日制人学学校证明。下载我们关于学校人学认证要求的情况说明书( PDF )如果您是再婚但再次单身的未亡配偶,还请发送结束您婚姻的法律文件副本。这可能是离婚判决书、死亡证明或宣告婚姻无效的判决书。请务必在您的申请上签名并注明日期。如果您的退伍军人代表您作为配偶申请，请务必在申请中注明结婚日期。将您的申请邮寄至: VHA社区护理办公室CHAMPVA资格认证邮政信箱469028丹佛,CO 80246-9028或传真至: 303-331-7809

# 提交申请后会发生什么?收到您的申请后，我们会进行审核,以确保其完整并包含所有必需表格。如果申请不完整，我们会将其退回给您，并附上更多说明。下载申请说明( PDF )

# 需要多长时间才能收到关于我申请的回复?

如果您向我们发送所有必需和可选文件，且您的申请完整，在我们收到您的材料包后，大约需要6周时间，您将收到CHAMPVA身份证及相关材料。如果您只发送必需文件，可能需要2到8个月，因为我们需要与其他联邦机构确认您的信息。

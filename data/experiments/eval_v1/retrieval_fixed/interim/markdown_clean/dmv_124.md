# 驾驶学校和教练的要求与表格

### 驾驶学校

驾驶学校是经DMV驾驶员培训项目局授权的商业企业，提供有偿驾驶指导，可能包括实际驾驶课程。DMV向符合条件开展驾驶学校业务者颁发驾驶学校许可证。许可证必须清晰展示在营业场所。在满足某些额外要求后，驾驶学校还可以

-向希望获得驾驶执照的个人提供DMV批准的5小时预许可课程\T]

-教授驾驶学校教练的基础30小时教练课程，现称为，

## 驾驶学校教练

驾驶学校教练是为持牌驾驶学校工作,教授学校客户如何安全驾驶机动车的人员。DMV向驾驶学校颁发教练证书( MV-524 )，用于教练获得该校任教资格后。教练在提供驾驶指导或陪同驾驶执照申请人前往路考地点时，必须随身携带此证书。在满足某些额外要求后，教练可获认证教授DMV批准的5小时预许可课程[1]给希望获得罗驶执照的个人。

## 驾驶学校的要求

驾驶学校必须满足多项要求，这些要求载于《专员条例》第76部分( PDF ) [2]和《纽约州车辆与交通法》第394条( PDF ) [3] ,包括

-驾驶学校必须有经批准的营业场所,包括

--对公众开放的办公室，以及

- -至少50平方英尺专用于驾驶学校业务运营的空间

- -必须展示的标识，置于显眼处:

- -驾驶学校许可证

--营业时间(办公室对公众开放的时间)

- -标明"必须向申请人提供所有付款收据”的标牌

- -可接受的收据和合同

- -可接受的记录保存

-驾驶学校必须至少有一名持证驾驶教练，且该教练具有至少1,000小时的实际驾驶教学经验。更多信息请参见《驾驶学校教练证书申请表》( PDF ) \4N] ( MV-523 )。

-如果驾驶学校提供5小时预许可课程，学校必须拥有

-- DMV批准的教室(位于营业地点或异地)，以及

- -至少一名获批准教授预许可课程的持证驾驶学校教练。

-所有用于驾驶教学或考试的车辆都必须使用驾驶学校车辆清单( PDF ) [54表格( MV-527 )向D MYV报告。每辆车还必须配备学生驾驶员标志，以及供教练使用的双控判车和后视镜。

-所有非教练的员工必须使用个人历史( PDF ) \6]表格( MV-521.1 )向DMV报告。

-如果驾驶学校教练被解屋，驾驶学校必须使用驾驶学校教练解懂通知( PDF ) [7J表格( MV-52 6 )通知DMV。

-驾驶学校所有者必须确保学校的所有广告(印刷、电子或其他形式)符合专员条例第76.21条( PDF ) \2的规定。如果您的企业被批准为驾驶学校，DMV可能会进行定期检查和审计，以确保您遵守这些要求。您还必须遵守您经营轰驶学校业务所在市政当局的所有规则和条例。

驾驶学校教练只有在受履于有执照的驾驶学校时才能获得认证。驾驶学校教练必须满足多项要求，这些要求在专员条例第76.15条( PDF ) [2]中有所规定,包括

-必须年满21岁

-必须持有在纽约州有效驾驶的轰驶执照,该执照:

- -在申请前至少2年内，在教练打算教学的车辆类别中有效，并且

- -在过去2年内未被暂停或吊销

- -显示可接受的驾驶记录

-必须拥有高中或高中同等学历文任

-必须通过要求的测试，包括

- -视力测试

- -路标测试

--笔试

- -驾驶学校教练驾驶测试

驾驶学校教练还必须在首次续签教练证书之前完成由专员批准的鸭驶员培训和交通安全课程，该课程至少包括30小时(称为)。这门30小时的课程由各个社区学院和经DMV批准提供此课程的驾驶学校教授。想要教授预许可课程的驾驶学校教练还必须成功完成30小时的教学技巧和方法课程(大学水平课程)，并且至少有一年作为经过认证的驾驶学校教练进行实际驾驶教学的经验。如需更多信息,请联系DTP :纽约州机动车辆管理局驾驶员培训项目局帝国大厦广场6号，327室奥尔巴尼,纽约州12228(518) 473-7174

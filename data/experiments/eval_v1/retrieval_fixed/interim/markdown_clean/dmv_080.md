# 纽约州保险要求

## 我需要保险吗?是的。要在纽约州注册车辆，您必须拥有纽约州签发的汽车责任保险。如果您未维持该保险, DMV可能会暂停您的车辆注册和驾驶执照。

## 我需要哪种保险?纽约州法律要求您拥有汽车责任保险。最低责任保险金额为

-单次事故财产损失$10,000

-事故中一人受伤$25,000及死亡$50,000

-事故中两人或以上受伤$50,000及死亡$100,000您的责任保险必须

-在注册有效期内持续有效，即使您不使用车辆(摩托车除外1 )

-为纽约州保险，由纽约州金融服务部许可并经纽约州DMV认证的公司签发-

## 州外保险一律不可接受

-以车辆注册人名义签发，并始终以注册人名义持有2纽约州金融服务部网站提供有关责任保险和纽约州许可保险公司的更多信息: http://www.dfs.ny.go v [1]。

## 车辆注册上超过两个名字

注册(注册人)只能有1或2个名字。主要注册人(注册上列出的第一个名字)和共同注册人必须签署车辆注册/所有权申请表( PDF ) [2] ( MV-82 )，并提供身份和出生日期证明。两个名字都必须出现在保险ID卡上。

## 我需要保险才能注册车辆吗?

是的。DMV要求在纽约注册车辆时必须拥有汽车责任保险。当您购买保险时,您的保险公司将以两种方式签发保险证明。它将

-给您两张纽约州保险ID卡原件(参见示例[3] )或提供您的数字电子纽约州保险ID卡访问权限3

-向DMYV发送电子保险通知(您的保险代理人或经纪人不能提交此通知)您的纽约州保险ID卡和电子保险通知共同证明您的保险。我们需要两者。

您必须在保险ID卡生效日期起180天内到DMYV注册您的车辆。携带一份或一种保险ID卡。DMYV办公室将保留纸质卡。将另一张纸质卡放在车内作为保险证明。任何操作您车辆的人都必须在操作时提供保险证明。

# 我的车辆注册申请和保险ID卡上的名字需要一致吗?是的。您的保险卡上的名字必须与车辆注册申请上的名字一致。

# 车管所会接受我的保险身份证件的复印件或传真件吗?会。但是，如果车管所的条形码读取器无法读取(扫描)条形码，车管所将不接受该证件。

## 州外保险文件

我们绝不会接受任何类型的州外车辆保险。如果您的车辆在纽约州注册,，则必须拥有纽约州的汽车责任保险。

- 1.您的摩托车在公共道路或高速公路上行驶时，必须始终有保险保障。与大多数其他机动车不同，摩托车的注册期限为一年而非两年，且所有摩托车注册均于4月30日到期。此外，您可以在不向车管所交回车牌的情况下终止您的摩托车责任保险。这使得摩托车在冬季存放后更容易重新上路。但是,在任何情况下，您的摩托车都不得在没有有效责任保险的情况下在公共高速公路上行驶。

- 2.保险单上的姓名若与注册证明上的姓名不同，可能导致保险保障中断，车管所可能会吊销您的驾驶执照和车辆注册。您车辆的保险和注册必须始终使用完全相同的姓名。您应始终在车内携带纸质或可访问数字电子纽约州保险身份证件。

- 3.电子纽约州保险身份证件不得用于以下情况:

--所有自有车辆( AOV )

--所有自有及非自有综合汽车责任保险( AON )

- -经销商车库汽车责任保险( DGP )

- -汽车责任保险( ALP )

--自保车辆

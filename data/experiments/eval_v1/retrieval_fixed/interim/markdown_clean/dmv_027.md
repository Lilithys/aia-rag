# 驾照与学习驾照费用及退款

### 学习驾照和驾照的费用

首次申请纽约州驾照或学习驾照，或因吊销后重新申请新驾照或学习驾照的费用，取决于申请时的年龄和居住地。总费用包括

- 驾照申请费
- 驾照类型费用（更多信息请参见驾照类别 [1]）
- 文件费
- 大都会通勤交通区（MCTD）费用（如居住于MCTD区域内）

### MCTD费用

以下县的居民必须支付大都会通勤交通区（MCTD）费用：

布朗克斯、国王（布鲁克林）、纽约（曼哈顿）、皇后、里士满（史泰登岛）、达奇斯、拿骚、奥兰治、普特南、罗克兰、萨福克和威斯特彻斯特。

MCTD费用为每6个月有效期收取 $1.00。

### 费用表

下表显示您需支付的总费用。表中未显示

- 商业驾照（CDL）费用
- 获取增强版驾照（EDL）而非普通驾照的额外 $30 费用
- 非驾驶员ID卡 [2] 的费用

* 包含MCTD费用

** Class M和MJ费用的一部分用于支持纽约州摩托车安全计划。

### 更换驾照或学习驾照的费用

更换驾照或学习驾照的费用为 $17.50。

### 更改驾照或学习驾照信息的费用

更改（修正）驾照或学习驾照信息的费用为 $12.50。

### 增强版驾照（EDL）或增强版学习驾照的费用

Enhanced Driver License需额外支付$30.00费用。

### 摩托车驾照费用

首次申请摩托车驾照所需支付的费用取决于

- 您目前是否持有其他类别的纽约州驾照，以及
- 申请时的确切年龄。

Class M或MJ驾照的费用，或在现有驾照上增加Class M或MJ的费用，范围从$21到$120。我们无法在您申请前计算确切费用。

### 我可以获得驾照费用退款吗？

如果您符合条件，可以获得8年驾照费用的部分退款。最高退款金额为原8年驾照费用的50%（即4年）。部分退款不包括任何申请费或文件费。

如果您符合以下条件，则有资格获得部分退款：

- 驾照签发时有效期为8年
- 在8年期限的前4年内将驾照交回给我们或另一州
- 交回时驾照未被吊销或撤销
- 未将驾照换成非驾驶员ID卡

申请退款，您必须：

- 在驾照签发日期后不超过51个月内申请
- 填写《机动车注册和驾照费用退款申请表》[3] (MV-215)
- 如果尚未交回驾照，请将驾照附在MV-215表格上
- 如果您将纽约州驾照换成了其他州的驾照，请将外州驾照的复印件附在MV-215表格上
- 将所需表格和文件邮寄至表格上所列地址
- 退款处理时间最长可达12周

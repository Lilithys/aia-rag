# 扩展计划 | 联邦学生援助

# 扩展还款计划允许您在较长时间内偿还贷款。

还款期限最长可达25年。

如果您需要在比标准还款计划等计划更长的时间内支付较低的月供，那么扩展还款计划可能适合您。

## 符合条件的联邦贷款

以下来自威廉·D·福特联邦直接贷款（直接贷款）计划和联邦家庭教育贷款（FFEL）计划的贷款符合扩展还款计划的条件：

- 直接补贴贷款
- 直接无补贴贷款
- 直接PLUS贷款
- 直接合并贷款
- 补贴联邦斯塔福德贷款
- 无补贴联邦斯塔福德贷款
- FFEL PLUS贷款
- FFEL合并贷款

## 扩展还款计划的资格

如果您是直接贷款借款人，您必须在1998年10月7日或之后获得直接贷款之日没有未偿还的直接贷款余额，并且您必须拥有超过30,000美元的未偿还直接贷款。

如果您是FFEL借款人，要符合此计划的条件，您必须在1998年10月7日或之后获得FFEL计划贷款之日没有未偿还的FFEL计划贷款余额，并且您必须拥有超过30,000美元的未偿还FFEL计划贷款。

例如，如果您有35,000美元的未偿还FFEL计划贷款和10,000美元的未偿还直接贷款，您可以为您的FFEL计划贷款选择扩展还款计划，但不能为您的直接贷款选择。

## 每月还款额

在此计划下，您的每月还款额为

- 固定或递增的金额，
- 最长还款期限为25年，并且
- 通常低于标准还款计划和递增还款计划下的还款额。

## 使用贷款模拟器估算您在扩展还款计划下的资格和还款金额

您的贷款服务机构，即处理您的联邦学生贷款账单和其他服务的公司，可以帮助您选择最适合您的贷款还款计划。在联系您的贷款服务机构讨论还款计划之前，您可以使用我们的贷款模拟器提前了解您可能符合条件的计划，并获得所有联邦学生贷款还款计划的预计月还款额比较。此比较很重要，因为扩展计划可能不会根据您的个人情况提供最低的还款金额。您可能会发现，在另一个还款计划下，您的还款额会更低。

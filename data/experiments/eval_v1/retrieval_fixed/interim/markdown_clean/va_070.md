# 申请你的军人服务记录(包括DD214 )

通过milConnect网站提交军人记录申请，以获取你的DD214或其他军人服务记录。

### 你需要登录milConnect才能获取你的军人服务记录

要使用此功能,你需要一个Premium DS Logon账户。你的My HealtheVet或ID.me凭据在milConnect网站上无法使用。前往milConnect登录、注册或将你的DS Logon账户升级为Premium。前往milConnect

## 登录milConnect后，我如何申请我的DD214或其他军人记录?

按照以下步骤提交军人记录申请。从已登录的主页, Ata AR Correspondence/ Documentation。然后从下拉菜单中选择Defense Personnel Records Information (DPRIS)。选择Personnel File选项卡。选择Request My Personnel File.填写表格。在Document Index B42 , Ait (RAB BAY SI SAE,点击或轻触Create and Send Request按钮。

## 我可以使用此工具申请哪些类型的记录?

您可以从您的官方军事人事档案Official Military Personnel File)中请求文件以查看和下载。您可以请求:

-DD214

-DD215

-退役报告( Report of Separation )

-其他退役文件您还可以请求包含您服役信息的文件，例如:

-命令和背书( Orders and endorsements )

-绩效报告( Performance reports )

-奖项和勋章(嘉奖物品)

-资格、执照和证书

-安全许可( Security clearance )

# 请求我的军事记录后会发生什么?

您籽收到一封电子邮件，告知我们正在处理您的请求。当您的请求完成且文件准备好供您查看和下载时，您将收到第二封电子邮件。您还可以通过登录milConnect并转到国防人事记录信息( DPRIS )部分内的"人事档案"选项卡来检查您的军事记录请求状态。这也是文件准备好后您查看和下载文件的地方。

# 还有其他方式获取我的军事记录吗?

是的。您可以通过以下任一方式申请您的军事记录:

-邮寄或传真《军事记录申请》(标准表格SF 180 )至国家人事记录中心( NPRC )。下载SF 180表格( PDF )

-写信给NPRC。寄至: 1 Archives Drive St. Louis, Missouri 63138

-亲自前往NPRC

-联系您所在州或县的退伍军人事务机构

-聘请独立研究员

# 如何申请他人的军事记录?

## 如果您是家属，计划将退伍军人安葬在VA国家公墓

请致电我们的国家公基调度办公室: 800-535-1117。我们可以帮助您获取可能需要的退伍军人DD214或其他退役文件。了解更多关于安排葬礼的信息

## 如果您是已故退伍军人的近亲

您可以通过以下任一方式申请该退伍军人军事记录的副本:

-邮寄或传真《军事记录申请》(标准表格SF 180 )至国家人事记录中心( NPRC )。下载SF 180表格( PDF )

-写信给NPRC。寄至: 1 Archives Drive St. Louis, Missouri 63138

-亲自前往NPRC

-联系您所在州或县的退伍军人事务机构

-聘请一位独立研究员如果您与退伍军人在以下任何方面存在亲属关系，您可能被视为其近亲:

-未再婚的未亡配偶,或

-父母,或

-子女,或

-兄弟姐妹

# 如果您不是退伍军人的近亲

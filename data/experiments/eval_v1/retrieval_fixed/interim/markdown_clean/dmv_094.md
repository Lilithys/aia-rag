# 支付暂停终止费

# 支付暂停终止费 [1]

暂停意味着你的驾驶执照（或驾驶特权）在被归还前被吊销一段时间。有两种类型的暂停。

### 定期暂停

定期暂停有明确的开始和结束日期。1 定期暂停的暂停终止费目前为 $50 2，除非暂停是因为违反 NYS Zero Tolerance 酒精法。该违法行为的暂停终止费为 $100。

### 不定期暂停

不定期暂停意味着你必须先做某事（如回应交通罚单），暂停才能被解除。3 根据法律，如果你收到 DMV 的定期暂停令，你必须在驾驶执照或驾驶特权恢复之前支付暂停终止费。

### 在线支付

要在线支付定期暂停费用，你必须提供

- 你的姓名或 NYS 驾驶执照、学习许可证或非驾驶员照片 ID 卡上的 DMV ID 号码（Client ID Number）（参见示例驾驶执照 [2]）
- 你的出生日期和性别
- 你的社会安全号码的最后四位数字

DMV 记录中的姓名和地址必须正确。4

你的支付不保证我们会恢复你的驾驶执照。你的记录中可能还有其他问题。在驾驶机动车之前，你有责任了解你的驾驶执照或驾驶特权是否有效。5

在线支付暂停终止费 [3]

### 在 DMV 办公室

你可以在暂停令上显示的一个或多个办公室支付暂停终止费。

### 通过邮件

在某些情况下，你可以通过邮件支付。如果暂停终止费可以通过邮件支付，你会在暂停令上找到说明。

### 常见问题

#### 我可以一次在线支付多笔定期吊销（definite suspension）的费用吗？

可以。您一天内最多可支付10笔吊销终止费（suspension termination fees）。

#### 支付费用后，如何查询我的驾照或驾驶特权状态？

您可以注册MyDMV账户[4]并使用My License服务。如需驾驶记录的认证副本，可订购您的驾驶记录副本[5]。

#### 我什么时候能拿回驾照？

定期吊销持续到吊销期结束。如果您在吊销期结束前支付了吊销终止费，我们将在吊销期结束后3个工作日内将驾照邮寄给您。6 在以下情况下，我们不会邮寄您的驾照：

- 您的驾照已过期
- 您持有商业驾照（CDL）7
- 您持有条件或限制性驾照8
- 您有其他吊销、撤销或驾照问题

#### 如何知道我的驾照是否已寄出？

支付吊销终止费后，在吊销期结束后等待3个工作日，然后使用我们的Photo ID Document Mailing Status服务[6]。

- 1. 定期吊销意味着您的驾照或驾驶特权被剥夺一段时间。如果您有定期吊销，您的吊销令会告知吊销期持续多久。

在吊销期结束、支付$50的吊销终止费并持有有效驾照之前，您不能驾驶。

定期吊销的常见原因包括

- 您没有购买汽车责任保险
  - 您因酒驾或毒驾被定罪
  - 您在特定时间内收到过多交通罚单
  - 您未遵守青少年驾驶员规定

- 2. 如果您的吊销令生效日期在2009年7月6日之前，吊销终止费为$25。

- 3. 不定期吊销（indefinite suspension）意味着您的驾照或驾驶特权因您未能履行某些事项而被剥夺。您的驾照或驾驶特权将保持吊销状态，直到您遵守吊销令上的指示。您可能还需支付吊销终止费。不定期吊销的常见原因包括
  - 您未回应交通罚单
  - 您未支付交通罚单罚款
  - 您未提交机动车事故报告
  - 您未支付子女抚养费

- 4. 您可以在线确认或更改地址，但必须先创建MyDMV账户[4]。如需更改姓名，您必须前往DMV办公室。

- 5. 如果您注册MyDMV账户[4]并使用MyLicense服务，即可在线查询驾照和驾驶特权状态。如需证明DMV已解除您的吊销，可订购驾驶记录的认证副本[5]。

- 6. 如果您上交了驾照，DMV将邮寄给您新证件，而非您上交的那份。

- 7. 虽然你可以在线支付暂停终止费用，但你必须前往 DMV 办公室才能取回你的商业驾驶执照。

- 8. 虽然你可以在线支付暂停终止费用，但如果你持有条件或限制性驾照，你必须前往 DMV 办公室才能取回你的完整驾驶执照。

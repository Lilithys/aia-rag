# 如何将注册转移到另一辆车

在您出售或赠送车辆后，您可以将注册和车牌转移到您拥有的另一辆车上。

### 携带以下物品前往DMV办公室 [1]

原始所有权证书（或其他所有权证明）1

当前的纽约州保险ID卡（汽车责任保险）2

纽约州驾驶执照、许可证、非驾驶员ID或其他身份证明3

填写完整的注册/所有权申请表（PDF）[2]（MV-82）

费用支付4

* *打印此清单** [3]

为了更快服务，请在访问纽约市、威斯特彻斯特、拿骚、萨福克、罗克兰、奥农达加、门罗或奥尔巴尼县的办公室之前在线预约。对于所有其他县，请查看我们的办公地点和营业时间 [1]。

进行预约 [4]

如果您不想转移注册，您必须将车牌交还给DMV [5]。如果您在注册到期前交还车牌，您可能有资格获得退款 [6]。

### 转移车辆所有权（购买、出售或赠送）

请参阅购买或出售车辆（转移所有权） [7]

- 1. **汽车、卡车、拖车和摩托车**

1973年或更新的车型年份，任一

- 纽约州所有权证书（原件或认证副本，非复印件），由卖方填写所有权转移部分，或
  - 来自其他州的可接受的所有权证明（原件或认证副本，非复印件）

1972年或更旧的车型年份，任一

- 纽约州可转让登记证明（原件或核证副本，不可用复印件）及销售单据 [8]，或
  - 来自其他州的可接受的所有权证明（原件或核证副本，不可用复印件）

请参阅其他车辆（活动房屋、船只、全地形车、雪地车、赠与车辆、车主已故的车辆）的可接受证明 [9]。

- 2.

您的保险公司将：

1\) 给您2张带有条形码的纽约州保险ID卡原件（参见示例 [10]）或为您提供访问数字电子纽约州保险ID卡的权限

2\) 向DMV发送电子保险覆盖通知（您的保险代理人或经纪人不能提交此通知）

您的纽约州保险ID卡和电子通知共同证明您的保险覆盖情况。我们需要两者。

您必须在保险ID卡生效日期起180天内注册您的车辆。随身携带一份保险ID卡的副本或形式。DMV办公室将保留纸质卡。将另一张纸质卡放在车内作为您的保险证明。任何操作您车辆的人都必须能够提供保险证明。

了解更多关于纽约州保险要求的信息 [11]。

- 3.

您必须提供身份和出生日期证明。您必须年满16岁（ATV和船只注册除外）。

您可以使用纽约州

- 驾驶执照
  - 学习许可证，或
  - 非驾驶员ID卡

作为身份和年龄证明，只要该证件是当前有效的或过期不超过2年。如果您没有这些证件，请参阅您可以使用的其他类型证明 [12]。

- 4. 如果注册属于以下类别之一，您可以在线估算注册费用 [13]

- PAS - 乘用车
  - COM - 商用车
  - RGL - 乘用车
  - MOT - 摩托车
  - ORM - 摩托车
  - CSP - 商用车
  - ORC - 商用车
  - RGC - 商用车
  - ORG - 乘用车
  - SPO - 乘用车
  - SRF - 乘用车

两辆车必须具有相同的注册类型（乘用车、商用车、摩托车）。

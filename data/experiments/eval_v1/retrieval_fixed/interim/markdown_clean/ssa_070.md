# 了解获取社会保障卡需要哪些文件 | 社会保障管理局

非公民子女的原始卡

一般来说，只有获得国土安全部（DHS）工作许可的非公民才能申请社会保障号。如果您的子女没 有工作许可但因其他目的需要社会保障号，请参阅“如果您的子女没有工作许可”以了解更多信息。

### 重要

您必须出示原始文件或由签发机构认证的副本。我们无法接受影印件或公证副本。所有文件必须是 最新的（未过期）。我们无法接受显示您已申请该文件的收据。

### 收养

在某些情况下，我们可以在收养完成前为您的收养子女分配一个号码，但您可能希望等待。然后， 您可以使用子女的新姓名申请号码。如果您希望在收养尚未完成时出于税务目的申报子女，请联系 美国国税局获取W-7A表格，即待处理美国收养的纳税人识别号申请表。有关更多信息，请参阅《 儿童社会保障号》（出版物编号05-10023）。

## 我需要哪些原始文件？

### 移民身份

为证明您子女的美国移民身份，您必须向我们出示您子女当前的美国移民文件，例如：

- I-551（合法永久居民卡，机器可读移民签证）；

- I-766（就业授权文件，EAD，工作许可证）；或

- I-94（抵达/离境记录）或未过期外国护照上的入境印章。

如果您的子女是F-1或M-1学生，我们必须看到您子女的I-20（非移民学生身份资格证明）。

如果您的子女是J-1或J-2交流访问者，您必须看到您子女的DS-2019（交流访问者身份资格证明） 。

### 工作资格

一般来说，只有获得DHS工作许可的非公民才能申请社会保障号。对于大多数外国工人，我们只需 要看到I-94（抵达/离境记录）或未过期外国护照上的入境印章，显示允许工作的入境类别。一些外 国工人必须出示DHS签发的I-766（就业授权文件，EAD，工作许可证）。

学生：如果您是F-1学生且有资格在校内工作，您必须提供指定学校官员出具的信函，该信函需：

- 确认您的身份；

- 确认您当前的学校状态；以及

- 确认您的雇主以及您正在或将要从事的工作类型。

我们还需要看到该就业的证据，例如最近的工资单或雇主的信函。您的雇主必须在信函上签名并注 明日期。信函必须描述：

- 您的工作；

- 您的受雇起始日期；

- 您正在或将工作的小时数；以及

- 您主管的姓名和电话号码。

如果您是获准参加课程实习训练（CPT）的F-1学生，您必须向我们提供您的I-20表格，其中就业页 需由您指定的学校负责人填写并签名。

如果您是F-1学生并持有国土安全部（DHS）签发的工作许可证（I-766），您必须出示该证件。

如果您是J-1学生、学生实习生或国际访客，您必须提供担保人的信函。信函应使用担保人信笺抬头 ，并带有授权您就业的原始签名。

如果您的孩子没有工作许可：合法入境的非公民可以在没有社会安全号码的情况下获得许多福利和 服务。您无需号码即可与银行开展业务、注册入学、申请教育测试、购买私人健康保险、申请学校 午餐计划或申请补贴住房。您不能仅为获得驾照而申请社会安全号码。

政府福利或服务：如果您的孩子没有工作许可，孩子仅在以下情况下可以申请社会安全号码：

- 联邦法律要求您的孩子提供社会安全号码才能获得特定福利或服务；或

- 州或地方法律要求您提供社会安全号码以获得您已有资格获得的公共援助福利。

如果您的孩子需要号码以满足这些州或地方要求，您必须向我们提供政府机构的信函。信函必须使 用官方信笺抬头（不接受格式信函或复印件），并且：

- 明确指明您的孩子为申请人；

- 引用要求您的孩子拥有社会安全号码的法律；

- 表明您的孩子满足该机构的所有要求，但缺少号码；以及

- 包含机构联系人的姓名和电话号码。

税务：如果您因税务目的需要为您的孩子获取一个号码，而您的孩子未获授权在美国工作，您可以 向美国国税局（IRS）为您的孩子申请个人纳税人识别号。请亲自前往国税局或拨打国税局免费电 话1-800-TAXFORM（1-800-829-3676），索取W-7A表格（待美国收养人纳税人识别号申请表）。

如果您被分配了一个非工作用途的号码，您不能使用该号码工作。如果您使用该号码工作，我们将 通知国土安全部（DHS）。

年龄

如果您持有或能在10天内获得您孩子的外国出生证明，您必须出示该证明。如果没有，我们将考虑 其他文件，如您孩子的护照或DHS签发的文件，作为您孩子年龄的证明。

任何年满12岁或以上申请原始社会保障号码的人必须亲自参加面谈。我们将要求提供证据证明您的 孩子没有社会保障号码。如果您的孩子在美国境外居住较长时间，可以使用当前或以前的护照、学 校和/或就业记录以及任何其他能证明在美国境外长期居住的记录，来证明您的孩子没有社会保障号 码。

身份

您的孩子：社会保障局将要求查看您孩子当前的DHS文件。可接受的文件包括：

- I-551永久居民卡；

- I-94入境/离境记录及未过期的外国护照；或

- DHS签发的I-766就业授权文件（EAD，工作许可）。

如果您的孩子没有当前的DHS文件，我们只能接受某些文件作为您孩子身份的证明。可接受的文件 必须显示您孩子的姓名、身份信息（如年龄、出生日期或父母姓名），并且最好有近期照片。如果 非照片身份文件有足够的信息来识别孩子（如孩子的姓名和年龄、出生日期或父母姓名），我们通 常可以接受。我们更希望看到孩子的美国护照。如果该文件不可用，我们可能接受孩子的：

- 收养法令；

- 医生、诊所或医院记录；

- 宗教记录；

- 学校日托中心记录；或

- 学校身份证。

您：我们还必须看到您的身份证明。可接受的文件必须显示您孩子的姓名、身份信息（即年龄、出 生日期或父母姓名），并且最好附有近期照片。例如，作为身份证明，社会保障局必须看到您的：

- 美国驾照；

- 州颁发的非驾驶员身份证；或

- 美国护照。

如果您没有这些特定文件之一，或者无法在10天内获得其中一份的补发，我们将要求查看其他文件 。提交的任何文件，包括以下文件，必须是当前有效的（未过期），并显示您的姓名、身份信息（ 出生日期或年龄），并且最好附有近期照片：

- 员工身份证；

- 学校身份证；

- 健康保险卡（不是医疗保险卡）；或

- 美国军人身份证。

如果您不是美国公民，社会保障局将要求查看当前的国土安全部文件。可接受的文件包括：

- I-551永久居民卡；

- I-94入境/离境记录，附有未过期的外国护照；或

- 国土安全部签发的I-766就业授权文件（EAD，工作许可证）。

### 注意

我们可能将一份文件用于两个目的。例如，我们可能将国土安全部的工作许可证用作移民身份和身 份的双重证明。但是，您必须至少提供两份单独的文件。

# 添加和移除用户

当DMV创建LENS名册时，我们会向申请人发放个人用户ID和密码。如果您的组织中有多人可能使用LENS，我们很乐意为您发放额外的用户ID。每位LENS用户都可以且应该拥有自己的个人登录凭据。请勿与他人共享您的登录信息或密码。

### 如何添加用户？

要获取额外的用户ID，请发送电子邮件至[email protected] [2]，并提供以下所有信息

- 您的5位数LENS名册编号
- 用户的纽约州驾驶执照/非驾驶员ID号码1
- 用户的完整姓名
- 企业名称
- 用户的办公地址
- 用户的办公电话号码
- 用户的办公电子邮件地址

然后我们将

- 将用户ID发送至用户的办公电子邮件地址，以及
- 将密码邮寄至用户的个人执照/ID邮寄地址。

密码是我们唯一发送到用户个人邮寄地址的LENS信息。我们不会将密码发送到办公地址。

### 如何移除用户？

如果LENS用户离开您的组织，您可以通过完成以下步骤将其移除：

1. 登录LENS
2. 访问LENS主菜单并选择“客户信息”
3. 选择“用户配置文件维护”
4. 点击“搜索”以列出您的所有LENS用户
5. 找到离职用户并勾选相应的“移除”框。点击“处理”。

如果LENS用户离开您的组织且您无法登录LENS，请发送电子邮件至[email protected] [2]。请注明该用户和您的LENS客户编号。我们将禁用已离职用户对您的LENS名册的访问权限。

### 如何更改用户？

如果有人接替另一用户的职责，请按照上述主题中的说明请求额外的用户ID。请勿与前用户共享前用户的ID和密码。我们不会为任何使用他人用户ID的人提供支持。一旦发现共享用户ID，我们可能会撤销这些ID。

# 联邦贷款与私人贷款 | 联邦学生援助

# 在支付大学、职业学校或研究生院费用时，联邦学生贷款相比私人学生贷款可以提供多项优势。

需要贷款来帮助支付大学费用吗？先考虑联邦贷款！

如果你申请经济援助，你的学校很可能会将学生贷款作为你经济援助计划的一部分。了解你被提供的贷款类型很重要。一般来说，有两种类型的学生贷款：联邦贷款和私人贷款。

- 联邦学生贷款和联邦家长贷款：这些贷款由联邦政府资助。
- 私人学生贷款：这些贷款是非联邦贷款，由银行、信用合作社、州机构或学校等贷方提供。

## 如果你需要借钱支付大学或职业学校费用，从联邦贷款开始。

联邦学生贷款是

- 直接补贴贷款和直接非补贴贷款，以及
- 直接PLUS贷款（针对研究生和专业学生）。

联邦家长贷款是

- 直接PLUS贷款（针对家长）。家长对这些贷款负有全部偿还责任，即使这些贷款是为了帮助学生而借的。

## 联邦学生贷款和私人学生贷款有什么区别？

联邦学生贷款由政府提供，其条款和条件由法律规定，并包含许多私人贷款通常不提供的福利（如固定利率和基于收入的还款计划）。

相比之下，私人贷款由私人组织提供，如银行、信用合作社以及州级或州附属组织，其条款和条件由贷方设定。私人学生贷款通常比联邦学生贷款更昂贵。

## 我如何获得联邦学生贷款？

要获得联邦贷款，你必须首先完成联邦学生援助免费申请（FAFSA）表格。了解更多关于申请援助的信息。

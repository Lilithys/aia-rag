# 车牌丢失、被盗或损毁

## 我的车辆牌照却失、被盗或损毁。我该怎么办?您必须向DMV交回车辆登记证。

如果两块车牌丢失、被盗或损毁(或者如果车辆只发放了一块车牌，例如摩托车，则是一块) ,您需要通知警方，并请警方完成一份警方报告。将警方报告带到DMV办公室[1]以交回车辆登记证。

-如果车牌在纽约州丢失、相盗或损毁，请纽约州警察机构填写一份'委失驾照、许可证或车牌证明' ( MV-78B ) (此表格仅可从执法机构获取一一它不在DMV网站上)

-如果车牌在纽约州以外委失、被盗或损毁,请获取一份印有事件发生地所在州警察机构抬头的报告如果您无法获得警方报告,请写一份声明,包括您的车牌号，并解释为什么您无法交回您的纽约州车牌。如果(一副两块中的)一块车牌委失、被盗或损毁，您无需完成警方报告。将您持有的那块车牌带到DMV办公室以交回登记。但是，如果您希望免费更换车牌，您必须提交一份警方报告或MV-78B ,表明该车牌是因犯罪而被盗或损毁。

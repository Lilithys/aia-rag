# Conditional 和 Restricted Use 许可证

你必须亲自到 DMV 办公室申请 conditional 或 restricted use 许可证。你可以在大多数（但不是所有）Motor Vehicles 办公室办理。请联系离你最近的办公室 [1] 以了解在哪里申请。

### Conditional

DMV 可以向符合条件的驾驶员签发 conditional license，前提是该驾驶员的 NY State 驾照因酒精或毒品相关的违规行为而被吊销或撤销。该驾驶员必须参加由 DMV 批准的 Impaired Driver Program (IDP) [2]（以前称为 Drinking Driving Program (DDP)）。

### Restricted use

DMV 可以向符合条件且其驾照因非酒精或毒品相关的违规或事故，或因某些毒品相关违规而被吊销或撤销的驾驶员签发 restricted use license。

### 来自其他州的驾驶员

如果你持有其他州签发的驾驶执照，并且满足其他要求，你可以获得在 NY State 驾驶的 conditional driving privilege 或 restricted driving privilege。其条件或限制与持有 NY State 驾驶执照的驾驶员相同。

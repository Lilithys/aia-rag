# 学习你需要哪些文件才能获得社会保障卡|社会保障署

### 外籍出生美国公民成人的换卡

如果你的社会保障卡丢失或被盗，你可以免费更换。然而，你可能并不需要更换卡片。重要的是要知道你的社会保障号码。一年内你最多只能申请三次( 3次)社会保障卡，一生中最多可以申请十次( 10次)。合法更改姓名不计和这些限制。此外，如果你能证明你需要卡片以避免重大困难，这些限制可能不会影响你。重要你必须出示原件或由发证机构认证的复印件。我们不接受复印件或经过公证的复印件。所有文件必须是当前有效的(未过期)。我们不接受显示你申请了该文件的收据。你可以在线申请你的社会保障卡的更换。我们的在线服务是一种快速且安全的方式获取更换卡。如果你是18岁或以上，有美国邮寄地址，并且有我的社会保障账户，你可以在线申请更换卡。有关创建我的社会保障账户和在线申请更换卡的更多信息，请访问我们的社会保障号码和卡网站。

## 我需要哪些原始文件?

公民身份如果你还没有向我们证明你的美国公民身份，我们需要看到证明你美国公民身份的文件。我们只和全接受某些文件作为证明你美国公民身份的文件。这些包括:

-美国护照;

-归化证书( N-550/N-570 ) ;

-公民证书( N-560/N-561 ) ;

-出生报告( DS-1350 ) ;

-外交部出生报告( FS-240 , CRBA)。身份我们只能接受某些文件作为身份证明。一个可接受的文件必须是当前有效的(未过期)，并显示你的姓名、身份信息(出生日期或年龄)和最好是近期的照片。例如，作为身份证明，社会保障必须看到你的:

-美国驾照;

-州颁发的非驾驶者身份卡;或

-美国护照。

如果你没有这些特定的文件，或者你无法在10天内获得其中任何一个文件的替代品，我们将要求你出示其他文件。任何提交的文件,包括以下文件，必须是当前有效的(未过期)，并显示你的姓名、身份信息(出生日期或年龄)和最好是近期的照片:

-员工身份卡;

-学校身份卡;

-健康保险卡(不是医疗保险卡) ;或

-美国军事身份卡。

我们可能会使用一份文件来证明两种身份。例如，我们可以使用你的美国护照来证明你的公民身份和身份。

# 支付暂停终止费

# 支付暂停终止费 [1]

暂停意味着在一段时间内你的驾驶执照（或驾驶特权）被收回，之后才会归还。有两种类型的暂停。

### 确定性暂停

确定性暂停有一个明确的开始和结束日期。1 确定性暂停的终止费目前为50美元 2，除非暂停是由于违反纽约州零容忍酒精法。这种违法行为的终止费为100美元。

### 无限期暂停

无限期暂停意味着在暂停被清除之前，你必须完成某些事情（例如回答交通罚单）。3 根据法律规定，如果你从DMV收到确定性暂停命令，你必须在恢复驾驶执照或驾驶特权之前支付暂停终止费。

### 在线支付

要在线支付确定性暂停终止费，你必须提供

- 你的姓名或DMV ID号码（客户ID号码）来自你的纽约州驾驶执照、学习许可或非驾驶人照片身份证（参见样本驾驶执照 [2]）
- 你的出生日期和性别
- 你的社会保障号码的最后四位数字

DMV记录上的你的姓名和地址必须正确。4

你的支付不能保证我们会恢复你的驾驶执照。你的记录中可能还有其他问题。在你驾驶机动车辆之前，你有责任知道你的驾驶执照或驾驶特权是否有效。5

在线支付暂停终止费 [3]

### 在DMV办公室

你可以在你的暂停命令上列出的办公室或办公室支付暂停终止费。

### 邮寄

在某些情况下，你可以通过邮寄支付。如果可以邮寄暂停终止费，你将在你的暂停命令上找到邮寄说明。

### 常见问题

#### 我可以一次性支付超过一个确定的暂停费用吗？

可以。您可以在一天内支付多达10个暂停终止费用。

#### 我支付费用后，如何查询我的驾照或驾驶许可状态？

您可以注册一个MyDMV账户[4]并使用My License服务。如果您需要驾驶记录的认证副本，可以订购您的驾驶记录副本[5]。

#### 我什么时候能拿到驾照？

确定的暂停将持续到您的暂停期结束。如果您在暂停期结束前支付了暂停终止费用，我们将在暂停期结束后3个工作日内通过邮寄方式将驾照寄给您。6 如果以下情况之一适用，我们将不会邮寄您的驾照：

- 您的驾照已过期
- 您持有商业驾照(CDL)7
- 您持有有条件或受限的驾照8
- 您有其他暂停、撤销或驾照问题

#### 我如何知道我的驾照是否已经寄出？

一旦您支付了暂停终止费用，请在暂停期结束后等待3个工作日，然后使用我们的Photo ID Document Mailing Status服务[6]。

- 1. 确定性暂停意味着你的驾驶执照或驾驶特权被撤销了一段时间。如果你有确定性暂停，你的暂停命令会告诉你暂停期将持续多久。

你必须在暂停期结束后才能驾驶，你需要支付50美元的暂停终止费并持有有效的驾驶执照。

常见的确定性暂停原因包括

- 你没有汽车责任保险
  - 你被定罪为酒驾或毒驾
  - 你在一定时间内收到了太多的交通罚单
  - 你没有遵守初级驾驶员的规定

- 2. 如果你的暂停命令的有效日期在2009年7月6日之前，暂停终止费是25美元。

- 3. 不确定性暂停意味着你的驾驶执照或驾驶特权因为没有完成某些事情而被撤销。你的驾驶执照或驾驶特权将保持暂停状态，直到你遵守暂停命令上的指示。你可能还需要支付暂停终止费。常见的不确定性暂停原因包括
  - 你没有回答交通罚单
  - 你没有支付交通罚单的罚款
  - 你没有提交交通事故报告
  - 你没有支付抚养费

- 4. 你可以在线确认或更改你的地址，但你必须首先创建一个MyDMV账户[4]。如果你需要更改姓名，你必须去DMV办公室。

- 5. 你可以通过注册MyDMV账户[4]并使用我们的MyLicense服务在线检查你的驾驶执照和驾驶特权状态。如果你需要证明DMV已经撤销了你的暂停，你可以订购一份驾驶记录的认证副本[5]。

- 6. 如果你放弃了你的驾驶执照，DMV将会邮寄给你一个新的文件，而不是你放弃的那个。

- 7. 虽然您可以在线支付暂停终止费用，但必须前往DMV办公室才能取回您的商业驾照。

- 8. 虽然您可以在线支付暂停终止费用，但必须前往DMV办公室才能取回您的完整驾照，如果您有临时或受限驾照。
